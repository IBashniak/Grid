# Симуляция устойчивости энергосистемы IEEE-118 методом Монте-Карло

Сквозной семестровый программный проект по курсу **«Грид-системы и технологии облачных вычислений»**.

Проект посвящен моделированию каскадных аварий в высоковольтной энергосистеме IEEE-118 (118 шин, 186 линий) методом Монте-Карло с постепенным наращиванием масштаба и архитектурной сложности: от локального MIMD на CPU до распределенного Ray Grid кластера, контейнеризации, облачной оркестрации в Kubernetes и стресс-тестирования Chaos Engineering & FinOps.

---

## 🗺️ Карта этапов проекта

- [x] **Этап 1: MIMD на CPU (локальный компьютер)**
  - Многопроцессорный пул (`multiprocessing.Pool`), обход GIL;
  - Санитарная обработка Z-score артефактов и отрицательных емкостей линий;
  - Изолированный генератор `random.Random(seed)` и каскадная эвристика N-k;
  - Чанкование задач, замер времени, Throughput и Speedup.
- [ ] **Этап 2: Грид-кластер на физических машинах (Ray Grid без Docker)**
  - Объединение 2–3 физических ПК в единый грид по локальной сети LAN;
  - Ray Object Store (`ray.put()`, Zero-copy shared memory);
  - Задачи `@ray.remote`, динамический диспетчер `ray.wait()` против Stragglers;
  - Оценка закона Густафсона-Барсиса.
- [ ] **Этап 3: Контейнеризация и микросервисы (Docker Compose + UI)**
- [ ] **Этап 4: Облачная оркестрация (Kubernetes / Cloud Jobs)**
- [ ] **Этап 5: Chaos Engineering & FinOps (Jaeger Tracing, OOM/Kill, Spot TCO)**

## 🚀 Быстрый старт (Этап 1)

### 1. Активация окружения
```bash
conda activate grid
```

### 2. Запуск симуляции (Бенчмарк MIMD)
Запуск 10 000 испытаний на 4 воркерах с первичным отключением $k=2$ линий:
```bash
python source/grid-mimd/main.py --trials 10000 --workers 4 --k 2
```

Для быстрого смоук-теста:
```bash
python source/grid-mimd/main.py --trials 1000 --workers 2
```

Результаты сохраняются в структурированный файл `benchmark_results_mimd_grid.json`.

### 3. Запуск автоматических тестов
```bash
pytest tests/ -v
```
Все тесты выполняются со 100% успехом (< 1 секунды).
